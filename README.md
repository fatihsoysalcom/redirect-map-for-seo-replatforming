# Redirect Map for SEO Replatforming

This Python script generates a 301 redirect map CSV file. It takes two input CSVs: one with old URLs and one with corresponding new URLs, demonstrating how to maintain SEO during a website replatforming.

## Language

`python`

## How to Run

1. Save the code as `redirect_mapper.py`.
2. Run from your terminal: `python redirect_mapper.py`.
3. Check for `redirect_map.csv` in the same directory.
